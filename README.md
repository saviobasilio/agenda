# agenda

Aplicativo para gerenciar sua agenda semanal, marcando todas as suas atividades e compromissos, com o intuito
 de te deixar mais produtivo e focado.

## Como executar

1. Instale as dependências padrão do Node (nenhuma dependência externa é necessária).
2. Inicie o servidor local:

```bash
npm start
```

3. Abra o navegador em [http://localhost:3000](http://localhost:3000) para acessar a interface.

## Funcionalidades

- Visualização semanal com dias na vertical e horas de 05h até 00h na horizontal, permitindo digitar atividades em cada célula.
- Visualização mensal da agenda com navegação entre meses e destaque do dia atual.
- Alternância rápida entre as visualizações semanal e mensal.
